Vice Cover Studio — turn your own photos into a dense, sun-soaked GTA 6-style
cover: a 7-panel comic grid with a pop-out hero, a huge striped gradient title
with a neon script subtitle, role labels on every panel, a location chip, a
starburst seal, a palm-silhouette strip and a catalogue footer. 8 layouts × 6
colour grades × 6 caption presets, drag-to-pan photos, one-click shuffle, and
PNG export at 1080×1080, 1080×1350, 1920×1080 and 1080×1920. Fully offline —
the 8 bundled sample photos and the Anton + Pacifico fonts ship in the repo.
No Rockstar Games logos, artwork or fonts are used anywhere.

## Run it

```sh
node main.ts
```

Then open http://localhost:8080 (or set `PORT`).

## How it works

1. Pick a layout (8), a grade (6) and a caption preset (6) — or hit Shuffle.
2. Drop in your own photos, or use the 8 bundled samples. Click a panel to
   select it, drag on the preview to pan, use the zoom slider to crop.
3. Edit the title, script subtitle, tagline, quote and every panel's role
   label. Choose an export size and hit Export PNG.
